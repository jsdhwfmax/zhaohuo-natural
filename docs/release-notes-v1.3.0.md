# v1.3.0 · 《活侠传》赵活美化管理器

将自然耐看、江湖俊朗、仙侠小师弟合并为一个可离线使用的完整包。三张卡片选择预览，点击“应用所选形象”后才安装或切换；同一时间只启用一种外观。

- 包含三套各 47 张成人立绘，共 141 张；共享插件 DLL、映射、布局和离线兼容探针保持原样。
- 正常受管、文件完整的公开自然版 v1.0.x，以及已知帅气版/小师弟版，可直接识别并升级或切换，保留首次安装备份，无需手动卸载。
- 支持三种形象之间切换；失败恢复切换前外观，卸载恢复第一次安装前状态。手改、误解压、未知文件或冲突配置会保守拒绝。
- 所有依赖随包提供。游戏更新后可重新“仅检查”，未知构建通过离线静态接口和资源检查才允许，不保证所有未来更新兼容。
- Windows PowerShell 5.1 下管理器专项 98 项、安装器回归 74 项、GUI/CLI 23 项通过，报告绑定当前代码。另在真实受管安装的必要文件副本上完成“小师弟→自然→帅气→小师弟”及重复应用，保留首次备份；该副本不是完整可运行游戏，该轮未改动正在运行的原游戏。
- 三套美术与共享插件字节未变，继续使用各自既有游戏加载/显示实机证据。副本文件事务验收与历史运行验证分开记录，不将其描述为本轮原地实机切换。

下载发行资产 **`ZhaoHuoPortraitManager-v1.3.0-win-x64.zip`**，完整解压到游戏目录之外，退出游戏后双击 **`打开美化管理器.cmd`**（或 `Install.cmd`）。GitHub 自动生成的 Source code ZIP 是源码快照，不等于带完整发行校验清单的安装包。

不要手动覆盖游戏目录，不要只下载脚本或 PNG。详细步骤见[安装、切换与恢复](https://github.com/jsdhwfmax/zhaohuo-natural/blob/v1.3.0/docs/形象管理器安装指南.md)。测试范围为文件事务、加载/显示及启动，不是全剧情、全路线通关。
