# 《活侠传》角色美化管理器 v2.2.2

游戏更新到 **1.0.6.04** 后，旧管理器可能提示 `globalgamemanagers.assets` 不兼容。这版已补好适配，原有角色和外观保留。

七位角色、十四套外观、447 张图片保持不变，包含上一版的大师兄女版手部修复。运行插件仍为 v2.1.0。

已装 v2.2.1 的朋友不用先卸载。保存并退出游戏，用新版完整包检查现有安装；记录、受管文件和首次备份完整时，保留原选择和备份。同款图片与插件没有变化，无需重新覆盖。需要换外观时再点“应用当前角色”。

下载正式附件 `ZhaoHuoPortraitManager-v2.2.2-win-x64.zip`，完整解压到游戏目录之外，再双击 `打开美化管理器.cmd`。GitHub 自动生成的 `Source code` 是源码归档，不是玩家安装包。[百度网盘](https://pan.baidu.com/s/1x2x7BX3lh0Rtwxb31IMobw?pwd=5ije)已同步 v2.2.2（提取码：5ije），原分享链接不变。

本轮在 Steam build `26021712` / `release_1.0.6000.4` 完成七角色各一款自定义外观、七角色原版模式及普通启动 92.4 秒验证，恢复原选择并核对备份、其他模组、游戏文件与存档。其余未变外观沿用历史证据；未加载剧情存档，不代表全剧情或全部第三方模组组合通过。
