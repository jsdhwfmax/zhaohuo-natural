# 《活侠传》角色美化管理器：安装、切换与恢复

本指南对应 v2.2.2：七位角色、十四套自定义外观及七个原版选项，完整包共 447 张替换图。已适配游戏 1.0.6.04（Steam build `26021712`、`release_1.0.6000.4`），验收范围见 [README](../README.md)。请下载正式发行附件中的完整离线包。

[最新完整安装包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/latest) · [当前常见问题](角色管理器常见问题.md)

网盘由维护者手动同步，请核对文件名为 v2.2.2；未看到新版时先用 GitHub。旧 v2.2.1 的兼容检查不支持 1.0.6.04，请使用新版完整包。

## 初次安装

1. 从[发行页](https://github.com/jsdhwfmax/zhaohuo-natural/releases/latest)下载正式附件 `ZhaoHuoPortraitManager-v2.2.2-win-x64.zip`，完整解压到游戏目录之外，例如桌面的独立文件夹。
2. 保存进度并退出游戏。
3. 双击 `打开美化管理器.cmd`，也可用 `Install.cmd`。点击“浏览文件夹”，选择包含 `Mortal.exe` 的 Steam 游戏文件夹。不要选 `Mortal_Data`，也不要选管理器所在文件夹。
4. 左侧选角色，右侧选择外观；可滚动查看。点击卡片只改变预览。
5. 点击“仅检查”，通过后点击“应用当前角色”。其他角色的选择不会随之改变。
6. 需要调整另一位角色时，重复选择与应用，再从 Steam 库正常启动游戏。

例如：赵活选“白衣少侠”、唐布衣选“明艳女侠”、龙湘选“精修版”、夏侯兰选“游戏原版”，可以同时使用。唐布衣与唐铮的女版只改变立绘，不修改剧情称呼或人物关系。

纯净游戏会安装随包官方 BepInEx 6.0.0-be.692 和 x64 Doorstop。已有匹配核心与配置会保留；其他版本、未知引导配置或文件冲突会显示原因。无需另下前置工具，也无需更改系统全局执行策略。

## 从旧包升级

有完整安装记录、受管文件和首次备份的正常安装，可以直接检查并应用，无需先卸载。支持已识别的旧自然版、帅气版、小师弟版、v1.3 管理器、v2.0 本地包及 v2.1.0 七角色包；不包含未经核验的早期私人格式或手工接管记录。

需要更新运行组件的旧安装，会在同一次操作中更新共享插件和角色配置，保留首次安装编号、首次备份及旧操作快照。由 v2.0 升级时，原有三位角色的选择保留，新四位角色默认“游戏原版”；本次应用的目标角色按你选择的款式设置。重复应用同一款会核验文件，已完成升级时无需重复覆盖。

v2.1.0、v2.2.0、v2.2.1 的完整受管安装可由新版识别，保留七位角色选择和首次备份。v2.2.1 到 v2.2.2 的图片与插件相同，同款检查通过后无需重复覆盖。硬汉版不会自动覆盖赵活当前外观，需要选中后点击“应用当前角色”。升级后统一使用新版管理器。不要把新版覆盖解压到游戏根目录或 `BepInEx/plugins` 内，也不要删除安装记录来绕过检查。

**更新大师兄女版修复图：** 退出游戏，用最新版管理器（v2.2.1 及以后）选择“唐布衣 → 明艳女侠”，点击“仅检查”，通过后点击“应用当前角色”。即使提示当前已经使用该款，也要应用一次，才能替换旧图；已完成后重复应用不会再次覆盖。其他角色不用重新安装。只打开新管理器，或只应用其他角色，不会更新唐布衣的图片。

## 只恢复某一位角色

选中该角色的“游戏原版”，点击“应用当前角色”。其他角色不变，公共运行组件仍保留；停用角色的图片可能作为受管缓存留在本模组目录里，但不会用于替换。

有些特殊图保留原作，包括单独手部、剪影和虞小梅两张含赵活的合绘。1.0.6.03 新增的虞小梅“疑惑”表情也暂用原画。这些是明确的覆盖边界，不代表安装失败。

## 全部卸载

保存并退出游戏，点击“全部卸载并恢复”。也可运行 `Uninstall.cmd` 打开窗口后点击该按钮。这会恢复第一次安装本模组前的状态，并处理全部受管角色。

修改过的受管文件会先保留，额外文件不会被直接删除。纯净游戏中首次由本包引入的运行库也会移除；安装前已存在且通过检查的核心会保留。后来安装的其他模组文件仍保留，但如果依赖本包引入的运行库，需要另行安装对应运行库。

要回到旧管理器版本，请先用当前 v2.2 管理器全部卸载，再从外部完整旧包重新安装；旧包仍须支持你的游戏版本。不要用旧 DLL 覆盖七角色安装。

## 安装器拒绝时

以下情况不能自动按普通旧版升级：

- 手工复制文件、曾接管手工包，或专用模组目录出现未知文件。
- 受管图片被修改或缺失，安装记录或首次备份损坏。
- 未识别的私人测试格式、加载器冲突，或游戏仍在运行。
- 游戏更新改变关键逻辑或资源，离线兼容检查未通过。

先保留错误提示与现有备份，不要盲删 DLL、安装记录或改哈希。有有效记录时可尝试用“全部卸载并恢复”后重装。确需归档的残余 `ZhaoHuoNatural` 专用目录，应放到 `BepInEx/plugins` **之外**，避免改名后仍被加载；不要移动其他模组。

更新游戏后重新“仅检查”。检查离线运行，不执行或改写游戏程序集。部分兼容更新可继续使用，关键变化需要新版适配，不能保证未来所有版本通用。

## 备份与中断恢复

活动记录：`BepInEx/ZhaoHuoNatural-install/ActiveManifest.json`。

原始备份：同目录 `Backups/<首次安装编号>/`。多角色操作快照位于其 `Transactions/<操作编号>/`，旧版已有的 `Switches` 快照保留，不覆盖首次原文件备份。

切换失败时尝试恢复本次操作前的文件与选择。断电等导致恢复未完成时，保留全部记录，再运行应用或全部卸载，管理器会先恢复未完成事务。“仅检查”只核对恢复材料，不写文件。中断后又被改动的文件先另存到 `PreservedDuringRecovery`；恢复材料损坏时停止并显示原因。

## 命令行

在完整包目录的 Windows PowerShell 5.1 中：

~~~powershell
$gamePath = Read-Host '请输入包含 Mortal.exe 的游戏目录'
.\Install.ps1 -GamePath $gamePath -CharacterId player -VariantId white -CheckOnly
.\Install.ps1 -GamePath $gamePath -CharacterId player -VariantId white
.\Install.ps1 -GamePath $gamePath -CharacterId tang-buyi -VariantId female
.\Install.ps1 -GamePath $gamePath -CharacterId long-xiang -VariantId refined
.\Install.ps1 -GamePath $gamePath -CharacterId yu-xiaomei -VariantId original
.\Uninstall.ps1 -GamePath $gamePath -CheckOnly
.\Uninstall.ps1 -GamePath $gamePath
~~~

| CharacterId | 角色 | 自定义 VariantId |
| --- | --- | --- |
| player | 赵活 | natural、handsome、xianxia、white、black、veteran、hardman |
| tang-buyi | 唐布衣 | refined、female |
| xiahou-lan | 夏侯兰 | refined |
| tang-moling | 唐默铃 | refined |
| long-xiang | 龙湘 | refined |
| yu-xiaomei | 虞小梅 | refined |
| tang-zheng | 唐铮 | female |

七位角色均支持 `original`。图形界面请使用 `打开美化管理器.cmd` 或 `Install.cmd`；直接运行 `Install.ps1` 会执行命令行操作，不传 `-GamePath` 时尝试定位唯一的 Steam 游戏目录。`-CheckOnly` 不执行安装或切换。
