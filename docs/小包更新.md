# 已经下载过，怎么只更新管理器？

旧的 **v2.2.1 至 v2.2.5 管理器文件夹**还在，就可以只下小包。更新器会从原文件夹复制立绘，在旁边生成一份完整的 v2.2.6 管理器。只剩旧版 ZIP 的话，先把它完整解压。请给新版预留约 **1 GB** 空间。

[下载 v2.2.6 小更新包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.6/ZhaoHuoPortraitManager-v2.2.6-small-update.zip) · [正式发行页](https://github.com/jsdhwfmax/zhaohuo-natural/releases/tag/v2.2.6)

## 操作步骤

1. 将小包完整解压到独立文件夹，放在游戏目录和旧管理器文件夹之外。
2. 双击 `双击更新管理器.cmd`，选**旧管理器文件夹**。点进去应该能看到 `打开美化管理器.cmd` 和 `VariantCatalog.json`。例如之前在桌面解压了 v2.2.5，就选桌面下含这两个文件的那一层。
3. 更新完成后，到旧文件夹旁边找到 `ZhaoHuoPortraitManager-v2.2.6-win-x64`。如果旁边已经有同名文件夹，更新器会停下来，供你查看已有的新版。
4. 保存进度并退出游戏，双击**新文件夹**里的 `打开美化管理器.cmd`，再选**游戏文件夹**。在 Steam 库右键《活侠传》，点“管理”→“浏览本地文件”，打开的就是含 `Mortal.exe` 的那一层。在管理器里先点“仅检查”，通过后再应用想用的外观。

正常旧安装无需卸载，七位角色的选择和首次备份由现有安装记录保留。生成新管理器这一步不访问游戏存档，也不安装或切换角色。

## 哪些情况需要完整包？

- 第一次使用，或旧版本为 v2.2.0 及更早版本。
- 旧完整管理器已经删除，只剩安装到游戏里的插件。
- 要复用的图片或依赖被删除、修改，检查无法通过。

已在用 v2.2.6 的玩家，可以直接打开管理器。以后 Steam 更新游戏时，退出游戏再点“仅检查”。检查通过就可以继续用，关键资源有变化则需要再适配。

## 校验与源码

更新器不运行旧文件夹中的脚本。每个复用文件都按随小包固定的目标 SHA-256 核验，复制后再核验；小包内的新文件也要核验。全部通过后才把临时目录改为正式的新目录。旧目录保持原样，多余的自定义文件不会被复制过去。

断电或强制结束可能留下名字以 `.zhaohuo-update-` 开头的临时目录。重新运行会创建新的临时目录，不会把半成品当作完成；确认没有更新正在运行后，可自行清理这类临时目录。

[运行器源码](../updates/Update-Manager.ps1) · [构建脚本](../scripts/Build-SmallUpdate.ps1)

维护者构建时，需要已校验的目标完整包、各受支持旧版本完整包，以及目标 `ReleaseManifest.json` 的独立确认哈希。构建器逐项核对实际文件，只把各旧版不能复用的文件装进小包，并把更新清单哈希写入运行器。生成后的目录还需与目标正式包完整比对，不能只凭版本号宣布通过。
