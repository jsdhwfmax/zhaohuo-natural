# 《活侠传》角色美化管理器 v2.2.6

Steam 版《活侠传》更新到了 1.0.6001.2（build `26844506`）。如果你在 v2.2.5 点“仅检查”时看到“游戏版本不受支持”，现在可以升级管理器了。七位角色原来的立绘都能接着用。

- **保留着 v2.2.1 至 v2.2.5 的完整管理器文件夹**，下载[小更新包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.6/ZhaoHuoPortraitManager-v2.2.6-small-update.zip)。单独解压，双击 `双击更新管理器.cmd`，选择旧管理器文件夹。新版会生成在旁边，请预留约 1 GB 空间。
- **第一次使用，或者旧素材已经删了**，下载[完整安装包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.6/ZhaoHuoPortraitManager-v2.2.6-win-x64.zip)，完整解压到桌面等游戏目录外的位置。

保存并退出游戏，从**新生成的 v2.2.6 文件夹**打开管理器。选择含 `Mortal.exe` 的游戏目录，点“仅检查”，通过后再应用想换的角色。遇到其他报错，请贴出“检测原因”和出现提示的那一步。

在 Steam build `26844506` 上，七位角色各选一套外观，实机检查了 150 张替换图和七人的原画回退。恢复测试前的角色选择后，从 Steam 正常启动并观察了 90.4 秒。这轮测试没有读取剧情存档。[实机测试记录](https://github.com/jsdhwfmax/zhaohuo-natural/blob/v2.2.6/verification/runtime-build26844506/compatibility-runtime.json)
