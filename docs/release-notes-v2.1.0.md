## 安装与切换

1. 保存并退出游戏，将完整包解压到游戏目录之外。
2. 双击 `打开美化管理器.cmd`，确认包含 `Mortal.exe` 的 Steam 游戏目录。
3. 选择角色与外观，点击“仅检查”，通过后点击“应用当前角色”。卡片只负责预览，其他角色需要分别应用。
4. 从 Steam 库正常启动游戏。下次切换也请先退出游戏。

完整包自带运行依赖，可离线检查、安装和切换。想恢复某位角色，选“游戏原版”并应用；想恢复整个模组首次安装前的状态，使用“全部卸载并恢复”。

正常通过旧安装器安装，且受管文件、安装记录和首次备份完整的旧版本，可由新版直接检查并应用，保留原有角色选择和最初备份。手工包或损坏记录请按提示处理。

## 适配与说明

- Windows x64、Steam 版《活侠传》，已在“崆峒神威”更新的 build `25957922` / `release_1.0.6000.2` 验证。
- 主要替换成人剧情立绘。指定剪影、单独手部和合绘保留原画，NPC 小头像、战斗小人与剧情 CG 不在本期范围。
- 不修改存档、台词、人物关系和剧情性别；师兄女版只改变立绘。
- 游戏更新后可主动运行“仅检查”。部分兼容更新能继续使用，关键变化仍需适配，不保证所有未来版本通用。
- 已验证安装升级、新 DLL 三组资源诊断、八套代表外观、七角色原版模式及普通 Steam 启动；其余五套赵活图片保持原字节，沿用历史美术证据。未做全剧情或全路线测试。
