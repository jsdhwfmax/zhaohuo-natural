# 《活侠传》角色美化管理器 v2.2.3

适配《活侠传》1.0.6.05。旧管理器提示 `globalgamemanagers.assets` 不兼容时，请换用新版完整包；只把旧包移到游戏目录外，不能解决这个版本报错。

这次保留七位角色、十四套外观和全部 447 张替换图，运行插件仍为 v2.1.0。正常通过旧管理器安装过、文件和备份完整的，无需先卸载。

下载 `ZhaoHuoPortraitManager-v2.2.3-win-x64.zip`，完整解压到游戏目录之外。保存并退出游戏，打开新管理器，选择包含 `Mortal.exe` 的游戏文件夹，先“仅检查”，通过后再“应用当前角色”。GitHub 的 `Source code` 是源码，不是玩家安装包。
