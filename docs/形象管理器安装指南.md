# 《活侠传》赵活美化管理器：安装、切换与恢复

v1.3.0 完整离线包包含自然耐看、江湖俊朗、仙侠小师弟三种形象，共 141 张成人立绘。游戏中只安装当前所选的一套 47 张，三个外观共用同一个插件。

## 初次安装

1. 从发行页下载 `ZhaoHuoPortraitManager-v1.3.0-win-x64.zip`。完整解压到游戏目录以外；不要只取 PNG、DLL 或某个脚本。
2. 保存游戏进度并退出游戏。
3. 双击 `打开美化管理器.cmd`，也可用原来的 `Install.cmd`。找到一个 Steam 目录时直接填入；多个时从下拉列表选择，或浏览到包含 `Mortal.exe` 的目录。
4. 点选形象卡片，查看预览与说明。选卡不会改变游戏文件。
5. 点击“仅检查”，确认通过，再点击“应用所选形象”。成功后从 Steam 库正常启动。

完整源码检出也包含运行所需内容，但 GitHub 自动生成的 Source code ZIP 不等于附带发行校验清单的安装包。普通玩家优先用命名的完整发行 ZIP。

纯净游戏会安装随包提供的官方 BepInEx 6.0.0-be.692 和 x64 Doorstop。已有相同版本时保留核心及配置；其它版本、未知引导配置或文件冲突会显示原因，不盲目覆盖。

## 从旧包升级或更换形象

正常通过旧安装器安装、具有完整记录且文件未改动的公开自然版 v1.0.0 / v1.0.1 / v1.0.2，可直接用本管理器检查和应用，无需先卸载。已知帅气版和修仙小师弟版也可识别；本管理器支持三种形象之间切换。

退出游戏，打开本管理器，选另一张卡片，再“仅检查”与“应用所选形象”。切换只处理当前记录拥有的立绘，插件 DLL、映射、布局与第一次安装的卸载恢复信息保持一致。应用当前形象不会重复覆盖。

保留完整外部管理器目录，之后切换不需要重新下载其它外观包。不要用旧的单外观安装器反向切换；统一使用本管理器。

## 安装器拒绝时怎么处理

完整来源需要正常安装记录及全部 50 个插件文件（47 张 PNG、DLL、映射和布局）的已知指纹。以下情况不能按普通旧版自动升级：

- 手工复制或误解压到游戏目录，或曾由旧自然版接管过手工文件。
- 缺少或改动受管文件，专用插件目录里有未知额外文件。
- 私人测试包、未知来源、损坏的安装记录或备份。
- 加载器冲突、游戏更新中，或兼容检查未通过。

保存提示和现有备份，不要盲目删 DLL、安装记录或改哈希。有正常安装记录时可使用“卸载并恢复”，再安装。需要保留的残余 `ZhaoHuoNatural` 专用目录应整体归档到 `BepInEx/plugins` **之外**；在 `plugins` 内改名可能仍会被加载。不要移动其他模组。

更新游戏后重新“仅检查”。未知构建要通过离线静态检查，可能比已知构建耗时；不需要联网，也不会修改游戏程序集。关键资源或逻辑变化时需等待新的兼容基线，不能保证所有未来更新通用。

## 备份、失败与中断恢复

安装记录位于游戏内 `BepInEx/ZhaoHuoNatural-install/ActiveManifest.json`；首次备份位于同目录 `Backups/<首次安装编号>/`。

切换前会另存 `Backups/<首次安装编号>/Switches/<切换编号>/`，各次快照并列保存，不覆盖最初原文件备份。失败时恢复本次切换前的外观；它不会追溯到更早的一套形象。

断电或文件占用造成恢复未完成时，保留所有记录，再用本管理器运行应用或卸载，工具会先恢复未完成事务。“仅检查”只核对恢复材料，不写文件。中断后用户另改的立绘会先另存到 `PreservedDuringRecovery`。备份缺失或校验失败时停止，不扩大删除范围。

## 卸载与恢复原游戏外观

保存并退出游戏，打开管理器，点击“卸载并恢复”；也可双击 `Uninstall.cmd` 打开卸载入口。它恢复第一次安装本模组之前的状态，不逐次退回历史外观。改动过的受管文件先备份，额外文件保留。

纯净游戏中首次由本包引入的运行库会随卸载移除。后来安装的其他模组文件不会被删除，但若依赖这套运行库，需要自行恢复相应运行库。安装前已存在且通过检查的核心会保留。

## 命令行

在完整包目录的 Windows PowerShell 5.1 中：

```powershell
$gamePath = Read-Host '请输入包含 Mortal.exe 的游戏目录'
.\Install.ps1 -GamePath $gamePath -VariantId natural -CheckOnly
.\Install.ps1 -GamePath $gamePath -VariantId handsome
.\Install.ps1 -GamePath $gamePath -VariantId xianxia
.\Uninstall.ps1 -GamePath $gamePath -CheckOnly
.\Uninstall.ps1 -GamePath $gamePath
```

`natural`、`handsome`、`xianxia` 分别对应三张卡片。GUI 入口只对当前进程设置执行策略，无需更改系统全局策略。
