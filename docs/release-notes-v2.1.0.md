# 《活侠传》角色美化管理器 v2.1.0

**v2.1.0 已完成本机验收。** 在 Steam build `25957922`、`release_1.0.6000.2` 上验证了实际安装升级、新 DLL 的代表性资源加载与普通启动；完整包的 400 张替换图及来源绑定通过校验。

新增唐默铃、龙湘、虞小梅精修版，以及唐布衣“明艳女侠”和唐铮“冷艳女侠”两套师兄女版。现在可以分别为七位角色选择外观，各自恢复原版，也能独立混搭。

- 共十三套自定义外观、七个原版选项；保留原有 312 张图片，新增五套 88 张，总计 400 张。
- 女版只改变立绘，不修改剧情性别、称呼、对白或关系。
- 单独手部、黑白剪影及虞小梅两张含赵活的合绘按角色保留原画，避免错误替换。
- 正常受管且文件、记录、首次备份完整的旧包可直接升级，保留原角色选择和最初卸载备份。v2.0 本地安装升级时，新加入角色默认原版；v2.0 本身仍是未公开的历史草稿。
- 安装器继续保护手改文件、其他模组与未完成事务；未知来源或受损安装会明确拒绝。
- 完整包离线附带运行依赖。游戏更新后可主动运行“仅检查”，通过保守兼容检查的部分更新无需更换美术包；不保证所有未来更新通用。

最终附件名称：`ZhaoHuoPortraitManager-v2.1.0-win-x64.zip`。保存退出游戏，将完整包解压到游戏目录之外，双击 `打开美化管理器.cmd`，选择角色与外观后点击“应用当前角色”。选卡本身不会改动游戏。

[完整安装、升级与恢复指南](https://github.com/jsdhwfmax/zhaohuo-natural/blob/v2.1.0/docs/形象管理器安装指南.md)

新 DLL 的三次游戏诊断覆盖赵活修仙小师弟、六位 NPC（含唐布衣两款）和七角色全部原版，普通 Steam 启动单独观察至少 90 秒。其余五套赵活保持原图字节并沿用历史美术证据，未宣称在新 DLL 下全部重跑。安装器、界面和离线检查另行记录；未做全剧情或全路线测试，未来仅部分兼容更新可通过离线检查。
