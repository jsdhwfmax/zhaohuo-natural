# 1.0.6.03 适配说明

v2.2.0 对应 Steam build `25987745`，游戏内版本字符串为 `release_1.0.6000.3`。玩家下载完整安装 ZIP 即可；无需自行编译或修改游戏文件。

## 为什么 v2.1.0 会提示不兼容

本次游戏更新改变了程序集指纹和资源文件，旧包的核验条件不再匹配。即使选择了正确的游戏目录，也可能被旧管理器拒绝。这种情况不应通过删除安装记录、修改哈希或强行覆盖 DLL 来绕过。

v2.2.0 增加当前构建的四个程序集完整指纹组，并附带独立的新资源基线。运行插件仍为经过验证的 2.1.0 DLL，原有 400 张立绘保持原字节。管理器的 2.2.0 与插件日志中的 2.1.0 是不同组件的版本，不代表装错包。

## 原版资源的变化

本轮比对了相关角色的 11 个资源包，其中 10 个与旧版字节一致。虞小梅的资源包新增了 `doubt`（疑惑）表情；原有 37 个精灵的像素和布局保持一致，角色映射仅增加这一项。

新增的“疑惑”表情暂用游戏原画。其他既有覆盖项继续替换，独立手部、剪影及含其他人物的合绘仍按原规则保留。详见[资源比对](../verification/game-resources-build25987745/resource-graph.json)和[原画回退规则检查](../verification/game-resources-build25987745/fallback-policy-tests.json)。

## 未来更新能否继续用

有条件可以，不能保证所有版本通用。

已验证构建按完整程序集指纹组识别。遇到未知构建时，离线探针会尝试已有的完整基线，核对相关文件集合、文件内容、关键实现和依赖；不会从两套基线里各挑一部分拼成“兼容”。只有满足核验条件的更新才会放行，关键变化仍需维护者验证并发新包。

这项检查由管理器的“仅检查”或应用入口触发，不会每次启动游戏自动执行，也不会联网下载或自动生成适配补丁。Steam 更新后先退出游戏，再运行新版管理器的“仅检查”。

## 安装与升级

1. 下载[最新完整安装包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/latest)，完整解压到游戏目录之外。
2. 保存并退出游戏，运行 `打开美化管理器.cmd`。
3. 选择包含 `Mortal.exe` 的目录，点击“仅检查”。不要选 `Mortal_Data` 或管理器解压目录。
4. 选择想用的角色和外观，再点击“应用当前角色”，最后从 Steam 启动游戏。

正常受管旧安装可以直接检查、应用，保留各角色选择和首次备份；新增硬汉版需手动选择。不要将新包直接覆盖解压到游戏里。完整步骤见[安装指南](形象管理器安装指南.md)。

本版静态兼容检查有 [23 项通过记录](../verification/compatibility-probe-tests-build25987745.json)。实际游戏验证另见[本构建运行报告](../verification/runtime-build25987745/compatibility-runtime.json)；静态检查不等于全剧情通关或未来版本实测。
