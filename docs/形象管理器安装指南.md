# 《活侠传》角色美化管理器：安装、切换与恢复

v2.0.0 完整离线包包含赵活六套外观、大师兄与夏侯兰各一套精修版，共 312 张替换图。每位角色独立选择，共用一个运行插件。

## 初次安装

1. 从[发行页](https://github.com/jsdhwfmax/zhaohuo-natural/releases/latest)下载 `ZhaoHuoPortraitManager-v2.0.0-win-x64.zip`，完整解压到游戏目录之外。
2. 保存进度并退出游戏。
3. 双击 `打开美化管理器.cmd`，也可用 `Install.cmd`。选择包含 `Mortal.exe` 的 Steam 游戏目录。
4. 左侧选角色，右侧点选外观。赵活外观较多，可向下滚动；选择卡片只改变预览。
5. 点击“仅检查”，通过后应用当前角色的所选外观。想换其他角色，再选角色并应用。
6. 从 Steam 库正常启动游戏。

例如：赵活选“白衣少侠”、大师兄选“精修版”、夏侯兰选“游戏原版”，三者可以同时使用。其他角色保持原画。

纯净游戏会安装随包官方 BepInEx 6.0.0-be.692 和 x64 Doorstop。已有匹配核心及配置会保留；其他版本、未知引导配置或文件冲突会显示原因。无需另下前置工具，也无需更改系统全局执行策略。

## 从旧包升级

通过旧安装器正常安装、受管文件和首次备份完整的公开自然版 v1.0.x、江湖俊朗版 v1.1、小师弟版 v1.2 及 v1.3 管理器，可以直接检查并应用，无需先卸载。

新版首次应用会升级共享插件和安装记录，保留首次安装编号与原始备份，并按本次选择更换指定角色。每次应用只改变当前角色选择；重复应用同一款会核验文件，无需重复覆盖。

升级到 v2 后请统一使用 v2 管理器。旧的单外观安装器和 v1.3 管理器不能管理新的多角色记录。不要把新版直接覆盖解压到游戏根目录或 `BepInEx/plugins` 内，也不要删除旧安装记录来绕过升级检查。

## 只恢复某一位角色

选中该角色的“游戏原版”，然后应用。其他角色的外观不变，公共运行组件仍保留；已安装图片可能作为缓存留在本模组目录里，但不会用于该角色。

恢复某一位角色，不需要全部卸载。要彻底移除本模组，再使用“全部卸载”。

## 全部卸载

保存并退出游戏，在管理器中点击“全部卸载并恢复”。也可以运行 `Uninstall.cmd` 打开窗口，再点击该按钮。这会恢复第一次安装本模组之前的状态，并处理所有受管角色。

修改过的受管文件会先保留，额外文件不会被直接删掉。纯净游戏中首次由本包引入的运行库也会移除；安装前已存在且通过检查的核心会保留。后来安装的其他模组文件仍保留，但若依赖这套运行库，需要另外安装对应运行库。

## 安装器拒绝时

以下情况不能自动按普通旧版升级：

- 手工复制过文件、曾接管手工包，或专用模组目录出现未知文件。
- 受管图片被修改或缺失，安装记录、首次备份损坏。
- 私人测试包、未知来源、加载器冲突，或游戏仍在运行。
- 游戏更新改变了关键逻辑或资源，兼容检查未通过。

先保存提示和现有备份，不要盲删 DLL、安装记录或改哈希。有有效记录时可用“全部卸载”恢复后重装。需要归档的残余 `ZhaoHuoNatural` 专用目录应放到 `BepInEx/plugins` **之外**，避免改名后仍被加载；不要移动其他模组。

游戏更新后重新“仅检查”。检查离线运行，不修改游戏程序集；部分兼容更新可继续用，关键变化需要新版适配，不能保证所有未来更新通用。

## 备份与中断恢复

活动记录：`BepInEx/ZhaoHuoNatural-install/ActiveManifest.json`。

原始备份：同目录 `Backups/<首次安装编号>/`。v2 的操作快照存入其 `Transactions/<操作编号>/`，旧版已有的 `Switches` 快照保留，不覆盖首次原文件备份。

切换失败时会尝试恢复本次操作前的文件和选择。断电等导致恢复未完成时，保留全部记录，再运行应用或全部卸载，管理器会先恢复未完成操作。“仅检查”只核对恢复材料，不写文件。中断后另改的文件先另存到 `PreservedDuringRecovery`；恢复材料损坏时停止并显示原因。

## 命令行

在完整包目录的 Windows PowerShell 5.1 中：

```powershell
$gamePath = Read-Host '请输入包含 Mortal.exe 的游戏目录'
.\Install.ps1 -GamePath $gamePath -CharacterId player -VariantId white -CheckOnly
.\Install.ps1 -GamePath $gamePath -CharacterId player -VariantId white
.\Install.ps1 -GamePath $gamePath -CharacterId tang-buyi -VariantId refined
.\Install.ps1 -GamePath $gamePath -CharacterId xiahou-lan -VariantId refined
.\Install.ps1 -GamePath $gamePath -CharacterId xiahou-lan -VariantId original
.\Uninstall.ps1 -GamePath $gamePath -CheckOnly
.\Uninstall.ps1 -GamePath $gamePath
```

赵活：`natural`、`handsome`、`xianxia`、`white`、`black`、`veteran`；大师兄和夏侯兰：`refined`；三位角色均支持 `original`。
