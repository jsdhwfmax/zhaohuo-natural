《活侠传》角色美化管理器：7 位角色可分别搭配，14 套外观、447 张表情与动作图，免费开源。

本版修正大师兄唐布衣“明艳女侠”的手部方向、手指与腕部衔接，保留现有画风和造型。其他 432 张图片及游戏运行插件不变。

### 下载与安装

下载附件 **ZhaoHuoPortraitManager-v2.2.1-win-x64.zip**，完整解压到游戏目录外。`Source code` 是源码归档，不是玩家安装包。

1. 保存并退出游戏，打开 `打开美化管理器.cmd`。
2. 选择包含 `Mortal.exe` 的游戏文件夹。
3. 选择角色和外观，先“仅检查”，通过后“应用当前角色”，再从 Steam 启动。

**已经装了旧女版：** 在新管理器里选择“唐布衣 → 明艳女侠”，检查后再应用一次。只打开管理器不会更新已安装的图片。正常受管旧安装可直接更新，保留原有角色选择与首次备份；无需先卸载。

### 适配与验证

适用于 Windows x64 Steam 版，已测试游戏 1.0.6.03 / build `25987745`。女版、精修男版和原画三组实机诊断通过，修复图 15/15 目视通过，普通 Steam 启动观测 90.7 秒通过。安装器与界面共 360 次断言执行通过，另有 69 项最终目录验收。测试未加载剧情存档，不代表全路线通关。
