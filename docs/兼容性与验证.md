v1.0.1 新增已验证的“崆峒神威”热更新 build `25957922`，保留 `25953419`。安装器核对 `Assembly-CSharp.dll`、`Mortal.Core.dll`、`Mortal.Story.dll` 和 `Fungus.dll` 的**完整 SHA-256 指纹组**，四个文件必须同时匹配同一个已验证构建。Steam 清单 build 用于诊断，不能代替文件核对；仅版本名称相同、单个哈希符合或不同构建的文件混配都不会因此放行。

没有对中间 build `25956595` 作实际游戏验证，它不在本版支持列表中。不要通过删除检查代码、替换游戏程序集或混装加载器来跳过提示。Steam 后续更新游戏后，请先查看是否有对应的适配版本。

| 角色正常 Setup 加载路径 | 通过 |

可公开复核的精简结果包括[新构建 25957922 的验证 PASS](../verification/runtime-build25957922/PASS.txt)、[原构建 25953419 的验证 PASS](../verification/runtime/PASS.txt)和[47 张 PNG 的完整性记录](../verification/art-integrity.json)。新构建的方法与字段兼容信息见[兼容检查记录](../verification/runtime-build25957922/compatibility.json)。原始个人日志不随仓库提供。

原构建另经不带验证参数的普通 Steam 启动确认：插件正常加载，识别到 47 张 PNG，游戏窗口持续响应。该次启动最后由测试用户手动关闭。新构建本次记录来自显式启用诊断的实际游戏进程，不把它描述为普通游玩或全路线通关测试。

## 这些结果不代表什么

这不是全剧情、全分支或全路线通关测试。人物关系与角色介绍界面的钩子已实现，但这些界面的完整交互流程未逐一操作验证。也没有穷举与其他第三方模组共同运行的组合。

安装器不会阻止 Steam 更新游戏。旧插件文件仍在目录中，不代表更新后的游戏已获适配；升级后如出现异常，请先卸载本包，再查看新版发布说明。

## 自行检查

日常游玩从 Steam 正常启动即可，不需要额外参数。遇到问题时可先在安装器中进行检查，并参考[常见问题](常见问题.md)。

用于复核资源链路的独立验证参数为：

```text
--zhaohuo-portrait-selftest --zhaohuo-selftest-exit
```

这组参数会运行验证并退出，**不能用于日常游玩**。如将它们临时加入 Steam 启动选项，验证结束后请删除。验证文件位于游戏目录中的 `BepInEx/plugins/ZhaoHuoNatural/Diagnostics/`，包括逐项结果和渲染预览。请勿把个人目录或完整日志未经检查地公开上传。
