# 1.0.6.05 适配说明

v2.2.3 已适配 Steam build `26073097`，游戏内部版本 `release_1.0.6000.5`。v2.2.2 的旧规则会拒绝新的 `globalgamemanagers.assets`；这不等于游戏目录选错或文件损坏。

本次独立核对立绘资源与相关代码，并增加完整的新资源基线，保留前三套基线。新旧基线分别检查，不拼接文件放行，也不跳过加载器、安装记录或受管文件保护。

七角色各一款自定义外观共 150 张替换图、七角色原版模式已完成实际游戏诊断。恢复原有选择后，普通 Steam 启动观测 91.8 秒通过。首次备份、其他模组、游戏文件与存档核验结果见[验证记录](../verification/README.md)。

运行插件仍为 v2.1.0，全部 447 张 PNG 和布局不变。其余七款外观沿用未变素材的历史证据，本轮未逐套重测；没有加载剧情存档，不代表全部剧情、路线或第三方模组组合兼容。

正常受管旧安装不用先卸载，退出游戏后用新版检查并应用即可。图片与插件未变时，同款无需重复覆盖。文件缺失、手工修改或未知冲突仍会停止，请保留报错和首次备份。
