# 1.0.6.04 适配说明

v2.2.2 已适配 Steam build `26021712`，游戏内部版本 `release_1.0.6000.4`。v2.2.1 对 `globalgamemanagers.assets` 的拒绝来自旧兼容规则，不足以判断游戏目录错误或文件损坏。

新包保留运行插件 v2.1.0、全部 447 张 PNG 和布局，只增加当前游戏构建的完整兼容规则。新旧规则分别核对，不混合资源放行，也不绕过加载器或文件保护。

七角色既有资源映射、Sprite 内容与头像引用已完成静态核对。实际 Steam 诊断验证七角色各一款自定义外观，共 150 张替换图，以及七角色全原版；恢复原选择后普通启动观测 92.4 秒通过。首次备份、其他模组、游戏文件与存档保持原字节。完整证据见[验证记录](../verification/README.md)。

其余七款外观未在本构建逐套重测，继续保留未变素材的历史证据。本轮未加载剧情存档，不代表全路线或第三方模组组合验证。

正常受管旧安装无需先卸载，保留原选择与首次备份。同款素材未变时无需覆盖；受管文件被修改、缺失，或存在未知模组冲突时继续停止。第三方扩展模组需要提供原帖、使用说明和版本单独核对，未确认前不承诺兼容。
