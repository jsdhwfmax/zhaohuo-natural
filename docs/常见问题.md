# 常见问题

## 这是官方更新吗？要收费吗？

不是官方更新，也没有官方背书。本项目免费提供；替换立绘使用 gpt-image 辅助重绘。下载入口以[GitHub 发布页](https://github.com/jsdhwfmax/zhaohuo-natural/releases)为准。

## 包里有游戏吗？

没有。需要已安装的 Steam 正版《活侠传》。发行包不提供原版游戏文件、提取出的原始立绘或游戏存档。

## 为什么剧情里还是说赵活长得不好看？

本包改变立绘显示，剧情设定、台词、数值与存档内容保持原样。

## 为什么有些造型没变？

v1.0.0 替换成人目录中的 47 张表情与动作，属性面板的两个常态分支也已覆盖。成人背影和左右剪影保留原作；幼年、老年、魔化、门派独立造型、战斗小人、剧情 CG 和其他角色不在本版重绘范围。

泥巴马赛克、受击残影、反色等效果是原作演出用途，新图有意保留。

## 我下载了 Source code，为什么不能直接安装？

GitHub 的 `Source code (zip)` / `Source code (tar.gz)` 是源码快照。请在版本发布页的 **Assets** 中选择本项目提供的安装包 ZIP，然后完整解压。

## 安装器提示游戏版本不匹配怎么办？

当前验证版本是 Steam build `25953419` / `release_1.0.6000.0`。请记录提示中的版本信息，到发布页查看适配情况。不要跳过文件检查或使用其他版本的游戏程序集强行安装。

## 已经装过 BepInEx 或其他立绘包，可以直接叠加吗？

先让安装器检查。已验证的 BepInEx 为 `6.0.0-be.692`，不是任意 BepInEx 6 都可用；BepInEx 5 与 IL2CPP 环境不受支持。多套立绘替换插件可能争用同一张图。安装器不能识别的其他模组组合需要分别确认，不能把一次检查通过理解为全部组合都已验证。

对旧 `BepInEx/plugins/Tianfei/MortalBeauty.dll`，安装器会备份后停用，卸载时恢复。它不会自动处理所有其他美化插件。

## 安装时需要联网吗？

完整安装包已包含所需运行库和加载器，安装过程可离线完成。请把发布包完整解压，不要只复制启动脚本。游戏本身仍需要事先通过 Steam 安装。

## 安装成功，但游戏里没变化？

1. 确认正在查看成人赵活的对话立绘或属性面板，而不是本版未覆盖的 CG、战斗小人或独立造型。
2. 完全退出游戏后，从 Steam 重新启动。
3. 在安装器中检查安装状态，并核对游戏目录中的 `BepInEx/plugins/ZhaoHuoNatural/` 是否完整。
4. 在 `BepInEx/LogOutput.log` 中搜索 `Zhao Huo Natural Portrait`。没有加载记录时，请将检查结果与错误片段提交给维护者。

## 游戏启动后自动退出？

先检查 Steam 启动选项是否仍有 `--zhaohuo-selftest-exit`；该参数供独立验证使用，会主动结束测试进程。日常游玩请清空本包的两个验证参数。

若没有测试参数，退出游戏后使用卸载入口恢复，再提供版本号和报错片段。不要通过反复覆盖不同来源的 DLL 排查。

## 会修改存档吗？

立绘插件用于运行时显示，不修改存档、剧情或角色数值。已进行的独立资源验证使用隔离的内存对象，没有推进剧情或读写玩家存档。

## 如何卸载？

退出游戏后，使用同一发布包的 `Uninstall.cmd`，按[卸载说明](安装与卸载.md)操作。请保留安装记录和备份，勿只删除整个 `BepInEx` 文件夹；其中可能还有其他模组。

如果原先是纯净游戏，卸载也会移除本包添加的运行库。后来安装的其他模组文件会保留；它们若依赖该运行库，需要另行重新安装兼容运行库。

## 游戏更新后还能继续用吗？

没有自动兼容保证。更新前建议卸载；更新后查看新版本说明，再通过安装器检查。已有插件不会阻止 Steam 更新，因此文件仍在不等于兼容。

## 如何反馈问题？

在[Issues](https://github.com/jsdhwfmax/zhaohuo-natural/issues/new/choose)中提供：模组版本、游戏 build、安装器提示、复现步骤、是否同时使用其他模组。截图和日志只保留必要片段，删去用户名、私人文件夹、账号及其他个人信息。请勿上传游戏资源、完整游戏 DLL 或存档。
