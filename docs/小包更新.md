# 已经下载过，怎么只更新管理器？

保留了 **v2.2.1、v2.2.2 或 v2.2.3 的完整解压文件夹**，就可以使用小更新包。它复用原有立绘，在本地生成与正式完整包内容一致的 v2.2.4 管理器，不必再次下载全部素材。

本次小包只有 **665,067 字节，不到 1 MB**。三个旧版本的真实完整目录均已重建成功，生成的 1196 个文件与正式 v2.2.4 逐项匹配。另有 43 项隔离检查覆盖损坏文件、路径保护与失败清理，见[验证记录](../verification/small-update-v2.2.4.json)。

[下载 v2.2.4 小更新包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.4/ZhaoHuoPortraitManager-v2.2.4-small-update.zip) · [正式发行页](https://github.com/jsdhwfmax/zhaohuo-natural/releases/tag/v2.2.4)

## 操作步骤

1. 将小包完整解压到独立文件夹，放在游戏目录和旧管理器文件夹之外。
2. 双击 `双击更新管理器.cmd`，选择**旧管理器文件夹**：里面应有 `打开美化管理器.cmd` 和 `VariantCatalog.json`。这一步不选 Steam 游戏文件夹。
3. 等待检查、复制完成。旁边会生成 `ZhaoHuoPortraitManager-v2.2.4-win-x64` 文件夹；旧目录保留，已有同名目标不会被覆盖。
4. 保存并退出游戏，打开新文件夹里的 `打开美化管理器.cmd`。此时选择包含 `Mortal.exe` 的**游戏文件夹**，先“仅检查”，通过后按需应用。

正常旧安装无需卸载，七位角色的选择和首次备份由现有安装记录保留。生成新管理器这一步不访问游戏存档，也不安装或切换角色。

小包减少下载量，本地仍会复制完整素材，目标磁盘请预留约 **1 GB**。确认新版可用后，可以自行清理外部旧管理器目录；游戏里的安装记录和备份要保留。

## 哪些情况需要完整包？

- 第一次使用，或旧版本为 v2.2.0 及更早版本。
- 旧完整管理器已经删除，只剩安装到游戏里的插件。
- 要复用的图片或依赖被删除、修改，检查无法通过。

已是 v2.2.4 的用户不用再运行本小包。更新器不联网，不会自动下载未来补丁。以后的游戏小更新若通过管理器兼容检查，可以继续用；关键资源变动仍需要适配。

## 校验与源码

更新器不运行旧文件夹中的脚本。每个复用文件都按随小包固定的目标 SHA-256 核验，复制后再核验；小包内的新文件也要核验。全部通过后才把临时目录改为正式的新目录。旧目录保持原样，多余的自定义文件不会被复制过去。

断电或强制结束可能留下名字以 `.zhaohuo-update-` 开头的临时目录。重新运行会创建新的临时目录，不会把半成品当作完成；确认没有更新正在运行后，可自行清理这类临时目录。

[运行器源码](../updates/Update-Manager.ps1) · [构建脚本](../scripts/Build-SmallUpdate.ps1)。独立更新器不修改 v2.2.4 已发布的完整 ZIP；完整包及其原 SHA-256 保持不变。

维护者构建时，需要已校验的目标完整包、各受支持旧版本完整包，以及目标 `ReleaseManifest.json` 的独立确认哈希。构建器逐项核对实际文件，只把各旧版不能复用的文件装进小包，并把更新清单哈希写入运行器。生成后的目录还需与目标正式包完整比对，不能只凭版本号宣布通过。
