# 《活侠传》角色美化管理器 v2.2.4

适配 Steam build `26237817`（游戏内部版本 `release_1.0.6001.0`）。下载了 v2.2.3 仍提示 `globalgamemanagers.assets` 不兼容，是这次游戏更新超出了旧包的兼容规则，请换用 v2.2.4 管理器。

**已经下载过？可以只下不到 1 MB 的小更新包。** 保留着 v2.2.1、v2.2.2 或 v2.2.3 的完整解压文件夹，下载 [`ZhaoHuoPortraitManager-v2.2.4-small-update.zip`](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.4/ZhaoHuoPortraitManager-v2.2.4-small-update.zip)。完整解压到独立文件夹，双击“双击更新管理器.cmd”，选旧管理器目录，检查后会在旁边生成新版。旧文件保留，不用重下立绘。小包在本地复制素材，磁盘请预留约 1 GB；只剩游戏内插件或旧版本早于 v2.2.1 时，仍需完整包。[详细步骤](https://github.com/jsdhwfmax/zhaohuo-natural/blob/main/docs/小包更新.md)

这次保留七位角色、十四套外观和全部 447 张替换图，运行插件仍为 v2.1.0。正常旧安装无需先卸载，原有选择和首次备份保留。

首次使用请下载 `ZhaoHuoPortraitManager-v2.2.4-win-x64.zip`，完整解压到游戏目录之外。保存并退出游戏，打开新管理器，选择包含 `Mortal.exe` 的游戏文件夹，先“仅检查”，通过后再“应用当前角色”。GitHub 的 `Source code` 是源码，不是玩家安装包。
