# ZhaoHuo Natural · 赵活自然美化包

为《活侠传》的成人赵活制作的非官方立绘模组。将面容调整为**自然耐看、保留草根侠客气质**的形象，延续原作的灰蓝布衣、束发、护腕与粗笔触画风，也保留各表情的情绪、伤势和动作。

本项目免费提供。美术使用 gpt-image 辅助重绘，以原作立绘为姿态与画风参考；不是官方更新，也不是原画作者的新作。游戏的剧情设定与台词保持原样。

**旧包提示“游戏版本不受支持”？** v1.0.0、v1.0.1 只认可各自收录的完整构建指纹，后续官方更新可能被旧安装器拒绝。请首次升级到 v1.0.2 **完整 ZIP**，退出游戏，解压到**游戏文件夹之外**再运行新的 `Install.cmd`；不要只换脚本或手动替换游戏 DLL。详见[热更新问题说明](docs/常见问题.md#游戏已经更新为何旧包提示版本不受支持)。

**更新后可复用保留的安装包检查。** v1.0.2 增加离线兼容检查：游戏小更新后，重新运行保留的 `Install.cmd` 并点击“仅检查”。游戏资源包、运行库保持不变，立绘依赖逻辑未变且符合其余基线条件的部分代码热修复，可继续使用，不必仅因整个 DLL 的指纹变化重新下载。剧情或资源包变化也可能被保守拒绝，需要等待新基线验证。检查由安装器触发，**不会在每次启动游戏时自动执行**。

如果此前误把安装包直接解压进游戏目录，也请先将新版完整包解压到外部文件夹运行；安装器会核对是否为原样解压的发行文件，再决定如何处理。不要为绕过提示盲目删除 DLL。见[误解压处理](docs/常见问题.md#已经直接解压到游戏目录怎么办)。

## 安装前先看版本

适用平台为 Windows x64、Steam 版《活侠传》（App ID `1859910`），搭配 **BepInEx `6.0.0-be.692`**。已实际验证“崆峒神威”热更新 build **`25957922`** / **`release_1.0.6000.2`**，以及原 build **`25953419`** / `release_1.0.6000.0`。v1.0.2 保留这两次运行验证的依据。

安装器区分“匹配已验证构建指纹”和“通过离线兼容检查”，后者不代表该游戏构建已经实机测试。未知构建需读取约 **2.30 GB** 的固定资源与运行库文件，可能比已验证构建的快速检查更久；不是只要 47 张原立绘没变就能通过。同样显示“崆峒神威”或相同版本名称，也不等于文件相同。BepInEx 5 和 IL2CPP 环境仍不受支持。详见[兼容性说明](docs/兼容性与验证.md)。

1. 从上方发布页下载**完整安装包 ZIP**，完整解压到**游戏目录之外**的独立文件夹。GitHub 自动生成的 `Source code` 压缩包供查看源码，不是安装包。
2. 在游戏内保存进度并退出游戏。
3. 双击 `Install.cmd`，在中文窗口中确认游戏位置并进行检查、安装。
4. 安装成功后，从 Steam 正常启动游戏。

完整安装包包含所需依赖和兼容基线，可离线检查、安装，无需另外安装检查工具。请保留整个外部安装包文件夹，后续游戏更新时复用它检查。详细操作、备份和回滚方式见[安装与卸载](docs/安装与卸载.md)。纯净游戏与已有加载器的处理由安装器检查决定；不要手工混装不同版本的加载器。

## 已做的验证

在 build `25953419` 与 `25957922` 各自的实际 Unity 进程中，成人目录均为 **50/50 个资源加载成功、47/47 张新图替换成功、属性面板 2/2 个分支通过**。同时检查了同步与异步加载、UI 引用、重复加载缓存及非主角保护。

精简结果可查看[新构建验证 PASS](verification/runtime-build25957922/PASS.txt)、[原构建验证 PASS](verification/runtime/PASS.txt)与[图片完整性记录](verification/art-integrity.json)。

两个已实测构建也分别通过不带诊断参数的普通 Steam 启动，确认插件加载和游戏窗口响应；新构建启动后连续观察约 81 秒。**这些结果是资源加载、显示链路和启动验证，不是全剧情、全路线通关测试。** 人物关系与角色介绍界面的完整交互流程也未逐一验证。更多边界见[验证说明](docs/兼容性与验证.md)。

v1.0.2 安装器在 PowerShell 5.1 中通过 **74 项集成回归检查**，使用独立模拟游戏目录与模拟的探针返回值，验证安装器的允许、拒绝和文件保护行为，见[当前安装器测试结果](verification/installer-tests.json)。真实离线探针另通过 **12 项专项检查**，覆盖实际游戏只读扫描、独立副本中的允许与拒绝场景及原游戏程序集未变，见[探针测试结果](verification/compatibility-probe-tests.json)。两组证据分别验证安装流程与静态兼容检查，不等于未来构建的实机测试。v1.0.1 的 55 项记录另存于[历史测试结果](verification/installer-tests-v1.0.1.json)。
