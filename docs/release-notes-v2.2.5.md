# 《活侠传》角色美化管理器 v2.2.5

如果之前一打开管理器就遇到“路径中具有非法字符”，可以试试这版。旧版遇到格式有误的 Steam 路径时可能中断查找。v2.2.5 会跳过这一项，继续找其他游戏库，也可以手动选游戏目录。

当前 Steam 公开版是 1.0.6001.0（build `26237817`）。这次沿用原有的游戏文件校验规则，七位角色的 14 套外观都可以继续用。

**已经有 v2.2.1 至 v2.2.4 的完整管理器文件夹**，只需下载[小更新包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.5/ZhaoHuoPortraitManager-v2.2.5-small-update.zip)。单独解压，双击 `双击更新管理器.cmd`，选择原来放 `打开美化管理器.cmd` 的文件夹。新版会生成在旁边，使用原有立绘，磁盘请预留约 1 GB。

**第一次用，或者旧素材已经删了**，请下载[完整安装包](https://github.com/jsdhwfmax/zhaohuo-natural/releases/download/v2.2.5/ZhaoHuoPortraitManager-v2.2.5-win-x64.zip)。例如在桌面建个「活侠传美化」文件夹，把整个 ZIP 解压进去。

保存进度并退出游戏，从新版文件夹双击 `打开美化管理器.cmd`。用“浏览文件夹”选中含 `Mortal.exe` 的游戏目录，点“仅检查”，通过后点“应用当前角色”。忘了游戏装在哪，可以在 Steam 库右键《活侠传》，点“管理”→“浏览本地文件”。

如果还遇到报错，请告诉我卡在哪一步，并贴上完整提示。看到“游戏版本不受支持”时，请一同贴出其中的 Steam build 和“检测原因”。
