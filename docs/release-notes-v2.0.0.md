# v2.0.0：三位角色独立换装

本次把赵活美化管理器扩展为角色美化管理器，沿用同一个项目和安装记录。

- 赵活新增白衣少侠、黑衣冷峻、成熟侠客，连同原有三套，共六套外观，每套 47 张表情与动作。
- 新增唐布衣（大师兄）和夏侯兰精修版，各 15 张对话立绘。
- 左侧选择角色，右侧预览并应用外观，可以自由混搭。
- 每位角色都有“游戏原版”，单独停用时不影响其他角色；全部卸载为独立操作。
- 通过安装器正常安装、受管文件和首次备份完整的公开旧版可直接升级，保留首次安装编号和原始备份；手工复制或误解压接管等特殊状态按提示处理。
- 切换失败可回滚，未完成操作再次运行时先恢复；“仅检查”不会写入游戏。

完整离线包名称：`ZhaoHuoPortraitManager-v2.0.0-win-x64.zip`。请下载发行页 Assets 中的这个完整包，完整解压到游戏目录之外，退出游戏后双击 `打开美化管理器.cmd`。不需要另下前置工具。详细步骤见[安装指南](https://github.com/jsdhwfmax/zhaohuo-natural/blob/main/docs/形象管理器安装指南.md)。

本期仅覆盖已识别的成人对话立绘。大师兄手部图、夏侯兰白色剪影及独立幼年、灵魂等特殊分支保留原画；NPC 小头像、战斗小人和剧情 CG 不替换。兼容检查能接受部分小更新，关键逻辑或资源变化仍需新版适配。

已在 Steam build `25957922` / `release_1.0.6000.2` 完成真实升级、六套赵活外观切换和各角色原版恢复。新插件的七次游戏内诊断全部通过，新增外观与 NPC 的 38 张游戏渲染截图已审阅，普通 Steam 启动进入主菜单并持续响应超过 90 秒。检查覆盖实际资源和 UI 加载，不代表全剧情通关。
